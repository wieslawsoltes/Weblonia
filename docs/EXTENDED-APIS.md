# Extended APIs — 0.2.0-alpha.1

All examples use the aggregate `@wieslawsoltes/avalonia` facade. Use the import
map generated by the source build, or install all local package tarballs with
their external dependencies. The examples assume an initialized application
and native Skia platform where rendering is involved.

## Container queries

```xml
<Border xmlns="https://github.com/avaloniaui"
        Container.Name="EditorHost" Container.Sizing="Width"
        Width="500" Padding="16">
  <Border.Styles>
    <ContainerQuery Name="EditorHost" Query="min-width:400">
      <Style Selector="TextBlock.responsive">
        <Setter Property="FontSize" Value="30" />
      </Style>
    </ContainerQuery>
  </Border.Styles>
  <TextBlock Classes="responsive" Text="Responsive retained layout" />
</Border>
```

The nearest eligible named ancestor supplies its arranged size. Width/height
eligibility is separate from the name. Query activation owns a style value; when
the condition becomes false it removes that value, revealing other priorities.
A local FontSize still wins. Resize and reparent subscriptions belong to the
style lifetime. Supported query primitives include width, height, aspect ratio,
orientation, comparisons, parentheses, and/or/not. Unsupported syntax throws.

## Native brushes, caching and effects

```js
import * as A from '@wieslawsoltes/avalonia';

const source = new A.Border();
source.Background = '#4261DB';
source.Width = 180;
source.Height = 90;
source.Child = new A.TextBlock('Cached visual');
source.Measure(new A.Size(180, 90));
source.Arrange(new A.Rect(0, 0, 180, 90));

const target = new A.Border();
target.Background = new A.VisualBrush(source);
target.Width = 360;
target.Height = 180;
source.CacheMode = new A.BitmapCache();
```

A visual brush snapshots through native Skia and tracks visual invalidation.
ImageBrush and VisualBrush use their Stretch, TileMode and alignment properties.
Recursive self-sampling is rejected. The caller owns the source control and any
input Bitmap; the renderer owns its cached native images. Changing source
content invalidates the cache rather than keeping a stale snapshot indefinitely.

ExperimentalAcrylicBorder samples and blurs the already-painted canvas. It does
not sample the user's desktop or create native OS acrylic.

## Committed composition and expressions

Run this after `host` has been attached to a browser TopLevel:

```js
const compositor = A.ElementComposition.GetElementVisual(host).Compositor;
const group = compositor.CreateContainerVisual();
const leader = compositor.CreateSolidColorVisual(A.Colors.Blue);
leader.Size = new A.Vector(80, 80);
leader.Offset = { X: 20, Y: 40, Z: 0 };
const follower = compositor.CreateSolidColorVisual(A.Colors.Red);
follower.Size = new A.Vector(30, 30);
group.Children.Add(leader);
group.Children.Add(follower);
A.ElementComposition.SetElementChildVisual(host, group);
await compositor.RequestCommitAsync();

const motion = compositor.CreateScalarKeyFrameAnimation();
motion.Duration = 1200; // JavaScript duration: milliseconds.
motion.IterationBehavior = 'Forever';
motion.Direction = 'Alternate';
motion.InsertKeyFrame(0, 20);
motion.InsertKeyFrame(1, 300);

const expression = compositor.CreateExpressionAnimation(
    'Vector3(360 - leader.Offset.X, 100 + Sin(leader.Offset.X / 30) * 20, 0)'
);
expression.SetReferenceParameter('leader', leader);
leader.StartAnimation('Offset.X', motion);
follower.StartAnimation('Offset', expression);

function disposeScene() {
    leader.StopAnimation('Offset.X');
    follower.StopAnimation('Offset');
    A.ElementComposition.SetElementChildVisual(host, null);
    group.Dispose(); leader.Dispose(); follower.Dispose();
    motion.Dispose(); expression.Dispose();
}
```

Assignments publish on commit. Animation presentation values do not overwrite
base property values. Parsed expressions do not execute arbitrary JavaScript.
Use `new A.Compositor({ Clock: new A.ManualClock(), AutoCommit: false })` for
repeatable non-browser tests. The compositor belongs to its TopLevel; avoid
disposing it when removing only one scene sharing that root.

## Native fonts, shaping and rich inline text

```js
// fontBytes must come from the embedding application. This package has no fonts.
const registration = platform.RegisterTypeface('ApplicationFont', fontBytes);
const text = A.AvaloniaXamlLoader.Load(`
<TextBlock xmlns="https://github.com/avaloniaui"
           FontFamily="ApplicationFont" FontSize="22" TextWrapping="Wrap">
  <Run Text="Hello " />
  <Bold>bold <Italic>and italic</Italic></Bold>
  <LineBreak />
  <Run Text="سلام — אבג — office" />
</TextBlock>`);

// Dispose registration only after views that rely on that registration are removed.
function disposeText() { text.Dispose(); registration.Dispose(); }
```

Registered run families select native SkParagraph shaping/bidi and line/cluster
metrics. The system-ui default remains browser-font rasterization composed by
Skia. Registration is explicit; no implicit font download occurs. Native rich
runs include style colors and InlineUIContainer placeholders. The paragraph
cache is bounded and evicted paragraphs can be rebuilt from descriptors.

TextBox caret/source positions remain UTF-16 indices; deletion and length limits
snap at grapheme boundaries. MaxLength is still a UTF-16 length budget, not a
count of graphemes: a cluster that does not fit is excluded intact. Browser
beforeinput deletion is intercepted where native deletion would split a cluster.
Password text is held by the model, but is not returned by automation Value or
copied into the mirror. The focused browser bridge is a native password input.

## TextFormatter source/line contract

```js
const run = new A.GenericTextRunProperties(
    new A.Typeface('ApplicationFont'), 18, null, A.Brushes.Black
);
const properties = new A.GenericTextParagraphProperties(run, 'Left', 'Wrap');
const source = new A.StringTextSource('First paragraph with wrapping.\r\nNext line.', run);
const cache = new A.TextRunCache();
let position = 0;
let previousBreak = null;
let y = 0;

for (;;) {
    const line = A.TextFormatter.Current.FormatLine(
        source, position, 240, properties, previousBreak, cache
    );
    if (!line) break;
    try {
        // drawingContext is an Avalonia DrawingContext supplied by Render.
        line.Draw(drawingContext, new A.Point(0, y));
        y += line.Height;
        position += line.Length;
        previousBreak = line.TextLineBreak;
        if (!line.Length) break;
    } finally { line.Dispose(); }
}
```

Implement TextSource.GetTextRun(index) for custom styled sources. Return
TextCharacters, TextEndOfLine, or TextEndOfParagraph. Non-advancing/invalid runs
are rejected and paragraph work has a size budget. Invalidate TextRunCache when
mutating a source. TextLine.Start is the horizontal origin, while
FirstTextSourceIndex is the source index. Range/caret APIs retain cluster-safe
positions. Black-pixel extent/overhang and all upstream typography strategies
are not yet exact; consult the compatibility contract.

## Real-cell read-only TableView

```js
const table = new A.TableView();
table.AutoGenerateColumns = false;
table.Columns.Add(new A.TableViewColumn('Name', new A.Binding('Name'), '2*'));
table.Columns.Add(new A.TableViewColumn('Role', new A.Binding('Role'), '*'));
table.ItemsSource = [
    { Name: 'Ada', Role: 'Architect' },
    { Name: 'Grace', Role: 'Compiler engineer' }
];
const role = table.Columns.Get(1);
role.CellTemplate = new A.DataTemplate(item => {
    const label = new A.TextBlock(item.Role);
    label.FontWeight = 600;
    return label;
});
```

CellTemplate receives the row object and takes priority over Binding. Bindings
are copied into one-way cell subscriptions, not evaluated on the column object.
Columns reject duplicate/cross-table ownership before mutation. Star/auto/pixel
widths are shared by headers and cells. Row recycling releases old subscriptions
and updates actual cell controls; it does not allocate 10,000 visual rows.
This is read-only TableView, not an editable DataGrid clone. Sorting and the
TextColumn/CheckBoxColumn convenience classes are JavaScript extensions.

## Automation peers

```js
A.AutomationProperties.SetName(button, 'Save document');
A.AutomationProperties.SetHelpText(button, 'Save the current document to a file');
const peer = A.ControlAutomationPeer.CreatePeerForElement(button);
peer.GetPattern('Invoke').Invoke();

const tablePeer = table.GetOrCreateAutomationPeer();
const cellPeer = tablePeer.GetItem(1, 0); // Table must already be measured/attached.
console.log(cellPeer.Row, cellPeer.Column, cellPeer.GetName());
```

Providers reject disabled actions and out-of-range values. Password Value is
empty. Control peers are cached and disposed with the owner. Table/selection
peers use bounded realized containers; virtual selected-item peers can request
realization. The browser mirror uses actual grid/row/cell/header semantics and
stable DOM identities. AutomationControlType values are descriptive JavaScript
strings. Physical platform automation and screen readers remain unqualified.

## Native HTML control hosting

```js
const nativeHost = new A.NativeControlHost();
nativeHost.Width = 320;
nativeHost.Height = 44;
nativeHost.NativeControlFactory = parentHandle => {
    const input = parentHandle.Handle.ownerDocument.createElement('input');
    input.placeholder = 'Browser-native input';
    input.style.cssText = 'width:100%;height:100%;box-sizing:border-box';
    return input;
};
```

The handle is an HTMLElement, not an OS pointer. The host tracks retained
transforms, ancestor clipping, focus, enabled state and removal. For custom
listeners, release the subscriptions from DestroyNativeControlCore or a control
lifetime disposable. The GL adapter similarly makes its platform substitution
explicit: WebGL2 callbacks and RGBA readback, not arbitrary desktop OpenGL.

## XAML constructors, factories and generic registrations

```js
class Product {
    constructor(name, count) { this.Name = name; this.Count = count; }
}
const registry = new A.XamlTypeRegistry().RegisterAssembly(A);
registry.RegisterType('Product', Product, 'urn:app', {
    FactoryMethods: { Create: [{
        Parameters: [String, Number],
        Invoke: (name, count) => new Product(name, count)
    }] }
});
const compiled = new A.AvaloniaXamlCompiler({ Registry: registry }).Compile(`
<Product xmlns="urn:app" xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
         x:FactoryMethod="Create">
  <x:Arguments><x:String>Document</x:String><x:Int32>3</x:Int32></x:Arguments>
</Product>`);
const product = compiled.Build();
```

RegisterGenericType supplies closed JavaScript constructors for x:TypeArguments.
Explicit parameter descriptors select constructors/factories, support optional
and variadic parameters, and reject ambiguous or invalid conversions. Typed arrays
validate members. Runtime and directly emitted AOT paths use the same construction
contracts. Registered constructors remain trusted application code.
